
# Blog Django

## Descripción
Aplicación web de blog desarrollada con Python y Django. Permite registrar usuarios y crear, consultar, editar y eliminar publicaciones.

## Funcionalidades
- Registro e inicio de sesión de usuarios.
- Crear publicaciones con título, contenido e imagen opcional.
- Consultar el detalle de cada publicación.
- Editar y eliminar publicaciones propias.
- Buscar publicaciones por título o contenido.
- Panel de administración de Django.

## Tecnologías
- Python
- Django
- SQLite
- HTML
- Pillow para el manejo de imágenes

## Instalación y ejecución

1. Clonar o descargar el repositorio.
2. Instalar las dependencias:

   pip install -r requirements.txt

3. Aplicar las migraciones:

   python manage.py migrate

4. Iniciar el servidor:

   python manage.py runserver

5. Abrir http://127.0.0.1:8000/ en el navegador.
